SD Prompt Manager 3.4 — Connected Odysee

26 July 20265 min read

It has been a while since the last release post, and SD Prompt Manager has quietly grown from "a prompt builder with a character library" into a full production environment for AI image work. Here is the tour of what landed.

The Prompt Builder

The builder is a two-column workspace: purpose-built input panels on the left (rating, hierarchical global style, shot & lighting, backgrounds, poses, characters), and a live prompt preview on the right that does far more than display text. The preview is editable in place, can be frozen against regeneration, and lets you click any individual tag to suppress it. A built-in Tag Check flags contradictions like a character who is standing, sitting and lying down at once.

Seven output modes — Standard, FLUX, Anima, Illustrious, WAN, Krea 2, Z-Image Turbo — change how the prompt is actually written: attention syntax stripped for natural-language models, tag soup rewritten into prose, artist vocabulary switched per model family.

Input syntax that compounds

A few small features change how fast you work:

  • Inline wildcards {red|emerald|midnight blue} anywhere a tag is accepted — seeded and deterministic, so the preview stays stable until you hit Reroll. Weighted variants like ({a|b}:1.2) work too.
  • Start a line with # to comment it out of the prompt without deleting it. A/B testing tags becomes one keystroke.
  • Group weights wrap whole tag groups as (tag one, tag two:1.20) instead of littering per-tag brackets.
  • @char1 placeholders resolve to real character names; @ca1 action lines route straight to character 1's block; @cp1 overrides its spatial position. All protected from AI rewrites.
  • Full wildcard-file support: TXT with sections, YAML with recursive cross-file references, per-card Random/Pick/Freeze controls, search-and-replace dictionaries.

Themes with an escalation ladder

Themes are reusable, self-randomizing tag packages across eight transformer categories (Theme, Pose, Expression, Hair, Makeup, Cloth, Body FX, Pop Char). Every theme carries up to five tiers — SFW, Suggestive, Artistic, Explicit, Extreme — and the pool format (fixed identity tags + variant groups + a random support pool) means the same theme produces a different-but-coherent tag set on every render. Transformer Collections bundle entries across categories and re-randomize within bounds on every render.

Boosters: model-aware vocabulary on tap

Six booster rows — Quality, Artist, Light, Camera, Style, Background — inject exactly the vocabulary the current model family responds to. FLUX gets cinematic photography language, Anima gets illustration tags, the Artist booster switches between photographer references, @handles and artist: tags per model. The roller never picks two tags from the same semantic family, tags already covered by your checkpoint's quality prompt are excluded, chips can be locked or hidden, and rolled sets save as named combos.

AI assistance, cloud to fully local

Seven providers: OpenAI, Gemini, Claude, Grok, GLM, OpenRouter — and Ollama for fully local inference. Global AI Suggest proposes complete scene concepts chosen from your actual libraries (it never invents entries you don't have), with match scores and a creativity slider. The AI Level Builder generates entire five-tier themes from a plain-language description. The AI Optimizer rewrites the whole prompt for a target model with 21 rulesets, including duration-aware video models. And a deterministic local prose rewriter restructures tag soup into natural language with zero API calls.

Characters as deep data

A character carries a region/area tag tree, a dedicated character LoRA routed through the LoRA pipeline, full anatomy configuration with content-tier support, character types with mix mode, facial structure fields (built to fight the same-face problem), and an ancestry system — 46 options describing facial structure only, never colors, so they can't fight your color wildcards. A dedicated preview modal gives every character its own test bench with live TAESD preview and a comparison filmstrip, and restores your production render config when you close it.

Jobs are the new center

The biggest structural change: the Prompt Builder is where you edit a job; the Job Board is where jobs live. Every job owns a fully independent workspace — characters, LoRAs, boosters, settings — so switching jobs never bleeds state. Three lanes (Working, Queue, Done), automatic queue processing, and level chaining: ComfyUI render to upscale to video, each level carrying the result forward, with future levels pre-configurable so an approved job advances into a prepared next stage.

A review modal with an AI anatomy check (a heads-up for finger and limb errors, not a verdict), auto-download of results into date-organized folders, native notifications, and a dashboard with live service balances round it out.

Render anywhere

Three ways to drive ComfyUI: the classic extension path (live workflow editing, mid-pipeline batch filtering, checkpoint rotation), the new Local Direct API — render on your own GPU with no ComfyUI tab open and no custom nodes installed, live preview included — and ComfyUI Cloud. Plus Wavespeed, Magnific, Venice and Bloom AI.

Any workflow node input can be exposed as an editable panel field, bypass groups work even though the API format has no bypass flag (the app rewires the graph), and regional prompting no longer needs custom nodes — the app extracts region masks from painted color maps itself and routes them onto any image input, which makes regional prompting work on plain Cloud workflows.

Coming soon

A mobile client is in the works: a PWA over your LAN with live render preview, a full character editor, gallery, and camera-roll reference upload — built on the Direct API so your phone can render without ComfyUI even being open on the desktop. Not merged yet, but close.

Version by version the idea has sharpened: the prompt is just the middle of the pipeline. Upstream sit characters, themes and checkpoint knowledge you curate once and reuse forever; downstream sit jobs, queues, chained services and publishing. The builder ties it together, the syntax keeps it fast, and the AI fills in what you don't feel like doing by hand.

SD Prompt Manager is free for Windows, macOS and Linux — grab it at valerie-4659.itch.io/sd-prompt-manager.
